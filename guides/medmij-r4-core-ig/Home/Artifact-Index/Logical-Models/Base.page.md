# Base

The Base Logical Model is a secondary Logical Model, in the sense that it is used as the base of other Logical Models, and that it is not used on its own in a dedicated granular data service. Note that the Base Logical Model is not used as base for the HealthProfessional, HealthcareProvider and Patient Logical Models, as most of the concepts in the former Logical Model are not relevant or applicable to the latter Logical Models.
